# QPR 与开闭环/RMS 主机验证

> 2026-10-08：当前主机闭环已改为电压 QPR + 电流 QPR。请运行
> `python Tests/verify_dual_qpr.py`，以及 `verify_slave.py`、`verify_vofa_mean.py`、
> `verify_vofa_frame.py`。下文、`verify_qpr.py`、`qpr_host_bridge.c` 和旧 JSON
> 属于原虚拟阻抗控制版本的历史记录，不适用于当前算法，也不代表当前验证通过。

这些检查直接用 GCC 编译 `Core/Src/qpr_control.c` 和 `Core/Src/inverter_control.c`，经小型 C 桥调用真实控制代码。Python 仅使用标准库；从 `singlephase.slx` 的 XML 提取 QPR 参数、原 MATLAB Function 的差分系数、虚拟阻抗及 LC 参数，作为独立 double 数值参考。脚本不执行模型中的回调、注释或任意代码。

在项目根目录运行：

```powershell
python Tests\verify_qpr.py
```

模型默认位置为 `D:\study\MATLAB-study\singlephase.slx`，也可以指定：

```powershell
python Tests\verify_qpr.py --model "D:\study\MATLAB-study\singlephase.slx" --compiler "D:\tools\mingw64\bin\gcc.exe"
```

结果保存在 `Tests/results/qpr_verification.json`，包含两个实际 C 源码、两个头文件、测试脚本、测试 C 桥及 SLX 的 SHA-256，另含编译器版本、参数和逐项误差。临时 DLL/共享库在系统临时目录构建，测试后移除。代码修改后应重新运行，不能把旧 JSON 当成新代码的验证结果。

## 覆盖范围

- 使用相同 float 输入驱动实际 QPR C 和 SLX 原差分式的 double 参考，比较 49/50/51 Hz、直流、阶跃及混合频率，同时记录原二阶差分直接改为 float 的误差。
- 对虚拟阻抗 `1/(0.001s+0.01)` 的 Tustin 离散结果作独立比较，保留原增益 `Kp=2、Kr=20、Wc=5 rad/s`。
- 检查 QPR 正负 48 V 限幅、调制度正负 0.96 限幅、饱和后内部状态自然恢复、数值异常及故障锁存/复位。
- 对 `QPR_ControlTrack` 做 81 组参考电压、反馈电压、电感电流和校正电压组合，验证紧接着的计算能接续指定校正量。
- 检查真正开环 `closed=0` 的 `m=reference_v/bus_v`，用 12000 拍有限反馈扰动确认反馈不改变开环输出；闭环仍运行模型对应的双环。
- 检查开闭环共用 `64 Vrms/s` 幅值斜坡：0→32 Vrms 约 0.5 s、32→16 Vrms 约 0.25 s，及输出暂停后从零斜坡重启。
- 检查 RMS 上下限、母线降低时的可用幅值限制、NaN/Inf、非法初始化和空指针。正常输出暂停会清运行状态；锁存故障必须显式复位，不能靠切换开环绕过。
- 检查未来按键调用的 RMS 设置/增减接口、非法值保持原命令、0～32 Vrms 钳位，以及开闭环与输出使能命令相互独立。
- 在六个固定相位检查切换不重置参考值，在 20 ms 校正量退出过程中反向切换，及连续 200 拍反复切换；另外用 12000 拍同时改变正弦相位、目标 RMS 和模式，比较共用参考斜坡是否连续。
- 将真实 C 接到精确零阶保持的理想差模 LC 平均模型，额外加入一拍 50 μs 控制/PWM 延迟，模拟 48 V 母线、32 Vrms 目标、2.2 μF、25 Ω，分别检查闭环、开环、运行中切换和连续反复切换。

实物“220 μH”尚未区分差模合计值与每桥臂数值，所以平均模型覆盖总电感 220 μH 和 440 μH 两种。母线为设定值，测试未加入实物母线下垂、开关压降或死区。32 Vrms 对应 45.2548 V 峰值，48 V 母线下理想调制度约 0.94281，接近 0.96 限幅，实物可用裕量需实际测量。

## 本次结果

实际 QPR C 在 50 Hz、1 A 幅值误差信号下，10 s 中最后 1 s 与 SLX double 参考的输出 RMS 差异约 `4.686e-5 V`；直接 float 二阶差分约 `0.03157 V`。虚拟阻抗的 50 Hz 数值 RMS 差异约 `2.620e-6 A`。81 组 Track 配平的校正量最大差异约 `4.78e-7 V`。这些是数值测试，不是实物电流或电压额定值。

| 25 Ω 平均模型 | 总 L=220 μH | 总 L=440 μH |
| --- | ---: | ---: |
| 连续闭环稳态输出 RMS | 31.99475 V | 31.99766 V |
| 连续闭环最大电感电流绝对值 | 1.81009 A | 1.81038 A |
| 连续闭环最大输出电压绝对值 | 45.24973 V | 45.25434 V |
| 连续闭环最大调制度绝对值 | 0.942668 | 0.942734 |
| 连续开环稳态输出 RMS | 32.00129 V | 32.00234 V |
| 普通切换时最大输出电压绝对值 | 45.46214 V | 45.50242 V |
| 连续反复切换时最大输出电压绝对值 | 45.61248 V | 45.68054 V |
| 四种运行场景各自调制度限幅次数 | 0 | 0 |

这里的稳态 RMS 取 2 s 仿真的最后 0.2 s。连续闭环的逐点 `(reference_v - voltage_v)` RMS 误差约为 0.402 V，基波相位约为 −0.72°；这与“输出 RMS 距 32 V 约 0.0053 V / 0.0023 V”是不同指标，不能混为一谈。

闭环退出时保留上拍校正量，再用 20 ms 退至零；转换期间仍含过渡校正，完成后为纯前馈开环。固定相位下的首拍连续性测试不等于实物切换绝对无冲击，动态平均模型已单独记录相邻拍变化和输出峰值。

额外保留的原 SLX 物理参数对照为总 L=600 μH、C=2.2 μF：50 Ω 在这个平均模型中未观察到振荡；500 Ω 出现明显振荡，最大电压绝对值约 88.22 V，不能算作通过工作点。500 Ω/空载不属于用户指定的 25 Ω 工作点，测试未自动修改原控制器增益。

**这是主机算法与理想平均模型验证，不是原 Simulink 开关模型运行，也不是 MCU 在线或实物测试。** 它不验证 ADC 比例/极性、开关纹波、驱动死区、实际采样延迟、保护、寄生参数或中断最坏执行时间。`checks_passed` 仅表示本文件列出的数值和软件行为检查通过，不代表所有负载均稳定。`output_enable=0` 对应零调制度，不代表硬件关断栅极。
