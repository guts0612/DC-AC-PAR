# 主机空载固件与数值审计（2026-10-14）

本报告核对 `D:/study/hal/DC-AC-PAR` 当前源码。控制文件对应原 HEAD `645207a`，本次没有修改 `qpr_control.c/.h`、PWM配置或控制增益。主机已由其他工作加入 CH8 RMS；以下控制链与试验直接使用当前真实 C。用户已确认：每只电感 220 µH、差模合计 440 µH，电容 2.2 µF，没有串联阻尼电阻；主开从关时 DM3058E 的 AC 档曾读到约 25 V，尚无同工况 VOFA RMS。

## 结论及证据层次

1. **主机电流 QPR 的数学移植与所给 BINLIAN 模型一致。** 原模型的二阶差分与当前双状态实现，在 49/50/51 Hz、0.1 A 电流误差下，最后 1 s 输出 RMS 差异分别为 `1.397e-7 / 5.822e-7 / 1.048e-7 V`。没有输出饱和，也没有故障。不能把空载问题解释为主机 PR 公式写错。
2. **整体 MCU 闭环不等于理想仿真对象。** 虚拟阻抗在模型是连续模块，在 MCU 是 Tustin 离散；MCU 采样后更新预装载，下一谷底才生效。所给模型的电容有串联 1 Ω，用户确认实物没有该电阻。母线、功率级参数、模拟反馈、从机物理连接也需按实际对象核对。
3. **真实 C + 理想平均 LC 可复现“12 Ω稳定、无阻尼空载不稳定”。** 440 µH / 2.2 µF / 一拍 50 µs 延迟时，12 Ω最终约 24.002 V RMS，无阻尼空载出现快速增长的高频振荡；取消一拍延迟或给电容串 1 Ω后，该理想对象空载稳定。因此阻尼与数字延迟是优先检验的方向。这是数学对象的反例，尚未证明实机 25 V 的根因。
4. **发现另一个从机 PR 数值缺陷，与本次从机关断的主机问题分开。** `QPR_CurrentStep()` 即使没有任何输出限幅，也可能因除母线再乘母线的浮点误差，错误冻结谐振状态。没有修改从机固件，详细证据见后文。

## 当前控制方程与参数

`Core/Inc/qpr_control.h:7` 起：`Kp=1 V/A`、`Kr=1.6 V/A`、`Wc=5 rad/s`、`f0=50 Hz`、`Lv=0.001 H`、`Rv=0.01 Ω`、QPR校正限制 ±5 V、调制度限制 ±0.95，参考 24 V RMS，对应 33.9411 V 峰值；峰值斜坡 60 V/s，约 0.566 s完成。

`Core/Src/qpr_control.c:247` 起实际运行顺序：

```text
vref = slewed_peak * sin(phase)
ev = vref - vout
ev_ac = ev - estimated_dc_error
iref = Tustin{1/(0.001s+0.01)}(ev_ac)
ei = iref - iL
uqpr = Tustin{1 + 2*1.6*5*s/(s²+2*5*s+(2π50)²)}(ei)
ubridge = vref + clamp(uqpr, -5 V, +5 V)
m = clamp(ubridge/Vdc, -0.95, +0.95)
```

主机在 `qpr_control.c:289` 起始终保存未饱和状态，没有抗饱和冻结或回算；这是明确实现行为，±5 V只限制输出，不限制内部虚拟阻抗/谐振状态。没有观测到持续饱和前，不能将此行为直接列为实机失稳根因。电压误差直流补偿是相对于原模型的新增环节：每400拍更新周期均值，以0.2 s参数平滑，幅值斜坡期间冻结均值收集。它消除电压反馈零偏经 `1/Rv=100 A/V` 放大后的直流指令，不能测量被电压互感器屏蔽的实际输出直流，也不能修正电流传感器零点。

`Core/Src/main.c` 的 `voltage_closed_loop_enable` 默认 **0（开环）**，PE0一次有效松手才切换闭环。PB9只控制从机。空载复测必须同时核对 `voltage_closed_loop_enable=1`、`slave_enable_request=0`、`slave_enabled=0`；“有输出”不等于“闭环已启用”。

## 采样、延迟和PWM路径

- `hrtim.c:63` 起：Master PERIOD触发ADC；Master8500、DIV1、REP0，A/B4250上下计数，谷底预装载。`main.c` 的 `HRTIM_SPWM_Init()`按170 MHz内核算出20 kHz，控制周期50 µs，每50 Hz周期400个样本。
- `adc.c:52`、`:169` 起两组主ADC都由HRTIM_TRG1下降沿触发，分别与ADC2/4双规则同步；12位差分、2.5cycle采样、PCLK同步DIV4。两组同触发不等于已测量四ADC的实际孔径一致，完整模拟链的增益/相位仍需测量。
- `dma.c` 两DMA IRQ同抢占优先级0；`main.c` 两个DMA回调先分别发布快照，后来的执行一次控制；重复一组而另一组未到/计数不匹配关断。正常主机只由该路径写A/B比较值，不存在第二个定时ISR竞争写主机PWM。
- `main.c` ADC回调的下一拍预装载注释和 `hrtim.c` 谷底更新设置一致。仿真中不能省略该一拍延迟。实际总相位还包括传感器、运放/RC、ADC采样、计算、PWM保持；本报告未测量MCU中断最坏耗时或这些模拟相位。
- `hrtim.c:151` 起主机死区当前为 A上升0/下降25，B上升0/下降0；从机C/D上升/下降各25。`.ioc`也相同。该不对称配置需要和实物驱动器的内置死区及栅极波形核对，本次没有改变它。
- `main.c` 的 `Slave_Stop()`禁用C/D栅极输出，计数器继续运行，也不控制交流接触器。**从机PWM关闭不等于从机滤波支路从公共输出断开。** 若其2.2 µF仍跨公共输出，总C可能约4.4 µF；本次数值审计已作为独立假设覆盖4.4 µF，尚未确定实物总C。

## 电流量级与RMS测量的边界

当前換算：电压 `V/code = 3/2048*12.8 = 0.01875 V`；电流 `A/code = 3/2048*2.400384 = 0.0035161875 A`。24 V / 12 Ω 时负载2 A RMS；空载2.2 µF在50 Hz下电容电流仅 `2π*50*2.2e-6*24 = 16.588 mA RMS`，约4.72个电流ADC码。若总C4.4 µF，该基波电流约33.176 mA RMS。

`verification/equal_input_20261013/等电压零点分析.md` 曾记录电流通道原码标准差15.90码（约55.9 mA）及完整传感器零点未覆盖的限制；`verification/dc_component_20261013/直流分量分析.md` 曾在另一份记录中观测电流反馈均值约32.84 mA、电压采样单周期RMS23.7279～24.1885 V。这些是旧记录，**不是本次空载同工况数据**，其当时增益与当前Kr也有变化。它们支持完整传感器供电、真实零电流的零偏/噪声复核，不能当作当前实机确认值。

CH8从和电压闭环相同的 `true_voltage` 全速样本计算RMS，可以排除“上位机用抽取后点计算RMS”及观察采样域RMS波动；仍无法独立证明输出真值、采样增益准确或仪表与采样链带宽一致。电压互感器不传直流时，此RMS只代表该传感器可传递的波形。约25 V对24 V差4.17%；如果CH8稳定24而仪表稳定25，需同步核对反馈增益及两路测量的频率响应，不能直接把反馈增益增加4.17%后宣称根因解决。

## 实际C + 平均LC对照结果

运行 `python verification/no_load_20261014/simulate_actual_c.py`，输出 `actual_c_lc_results.json`。对象状态为电感电流 `iL` 和电容电压 `vC`，测量负载节点电压。负载R、电容串联Rc时：

```text
alpha = R/(R+Rc), beta = Rc*alpha
vout = alpha*vC + beta*iL
diL/dt = (ubridge-vout)/L
dvC/dt = (alpha*iL-vC/(R+Rc))/C
```

空载采用极限 `vout=vC+Rc*iL`。使用精确矩阵指数和精确零阶保持输入，并分别采用0/1拍延迟，非Euler积分。独立验证无损LC矩阵相对解析正弦/余弦最大误差 `1.78e-15`，3 s零输入能量相对误差 `6.73e-12`，避免将积分算法自身失稳误作控制失稳。算法保留实际软启动、DC补偿、±5 V校正和±0.95调制度限制。

## 独立的从机PR诊断

`qpr_control.c:48` 起条件抗饱和：

```text
if error*(raw-correction)<=0 && error*(bridge-modulation*dc_bus)<=0:
    save resonant states
```

当未限幅时，`modulation=bridge/dc_bus`，但单精度 `(bridge/dc_bus)*dc_bus` 不一定恰等于 `bridge`。以48 V、0.1 A输入、10 s运行：

| 频率 | 从机原状态未更新的步数 | 正的round-trip乘积步数 | 相对模型RMS差 |
|---|---:|---:|---:|
|49 Hz|7372|7372|0.11216 V|
|50 Hz|12834|12834|0.10959 V|
|51 Hz|13626|13626|0.05449 V|

全部校正限幅计数与故障仍为0。在诊断中只把母线改成二的幂64 V，除/乘可以精确复原：所有错误冻结消失，49/50/51 Hz相对模型RMS差降至 `0.145 / 1.213 / 0.150 µV`。这独立证实浮点round-trip比较会误触发冻结。后续修从机时应先判断是否真的发生限幅，再按饱和方向冻结，不能对未饱和的除乘残差判断。

此处 **只诊断，没有修改从机程序**。本次用户工况从机PWM关闭，该路径不会运行，不能把它归为主机空载根因。

## 可证伪的检查顺序

1. 同时记录 CH8、CH1参考、CH2输出、CH4电感电流、CH7母线与DM3058E读数，确认主闭从关，分别保持12 Ω与空载稳定区段。若CH8也约25且波动，问题已在采样/控制域可见；若CH8稳24而仪表25，优先测量链/频响/校准核对。
2. 输出、电感电流用能覆盖LC频段的示波器观察。440 µH/2.2 µF理想谐振约5.115 kHz，总C4.4 µF时约3.617 kHz；这些是计算值，不是已测振荡频率。若空载出现该频段显著振荡而12 Ω衰减，则支持阻尼/延迟假设；若只有慢漂且没有该频段，应调整优先级，不据本数学对象强行归因。
3. 查明从机关断时公共输出实际总C及停机支路电流。软件关断不能证明物理断开；模型“从机默认参与”也不能等同当前实物“从机关断”。
4. 保持完整传感器/模拟链正常供电，真实零电流时测量ADC零点与波动，另用已知幅值50 Hz信号校准电压比例。若误差只在ADC模拟输入等压标定后出现，完整传感器零偏/共模/输出阻抗是可检验方向。
5. 用Watch观察限幅计数的增量、`qpr_unlimited_v`与`qpr_correction_v`。若空载失稳期间无饱和增长，不能把抗饱和当首因；若饱和持续且内部状态增长，需对外环/内环状态限幅与退出路径另行建模。
6. 核对实际A/B栅极死区、模拟反馈相位和中断提交时间，再在与实物一致的开关/离散模型中调整阻尼或控制器。禁止用“PR数值等价”替代闭环对象验证。

本报告没有烧录、没有读到本次空载波形，也没有计算已确认工况的实际负载调整率。实际 SI 必须使用同一测量定义、同一仪表或同一标定采样链的空载Uo1和2 A负载Uo2；若最终确认为空载25 V、2 A时24 V，则按所述分母Uo1得到4%。
