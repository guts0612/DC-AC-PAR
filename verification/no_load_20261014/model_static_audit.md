# BINLIANSinglePhase.slx 与当前固件的静态对照

审计日期：2026-10-14。原模型未保存修改；下面的数值和连接直接来自原 SLX 与当前源文件。

## 模型控制链

主机：`vref-vout → 1/(0.001s+0.01) → iref-iL → Digital PR → ±5 V → +vref → /Udc → 单极性 SPWM`。

从机：`iL主×1-iL从 → Digital PR → ±5 V → +vout → /Udc主 → SPWM`。两个桥默认同时运行。

两组 PR 参数均为 Kp=1、Kr=1.6、Wc=5 rad/s、W0=2π×50 rad/s、Ts=50 µs。原 MATLAB Function 使用 Tustin 二阶差分，限幅在函数外，函数内部保存未限幅状态。

MATLAB R2023b 的编译输出已实测确认两个 Stateflow MATLAB Function 块的 `CompiledSampleTime=[5e-5,0]`，与控制系数所用 Ts 一致。`Ts` 不只是传入函数的数字：chart 中明确设置 `updateMethod=DISCRETE`、`sampleTime=Ts`。

当前固件 `qpr_control.c/.h` 的主机结构、PR 系数参数、前馈次序和 ±5 V 限幅对应上述模型。双状态 PR 是同一 Tustin 传递函数的等价状态实现。虚拟阻抗从模型连续模块改为 20 kHz Tustin 离散；固件另加幅值软启动、调制度 ±0.95 限幅、输入/数值检查以及电压误差直流估计补偿。没有按负载值选择控制器，也没有空载禁用闭环的分支。

仓库 `QPR移植说明.md` 中 32 Vrms、Kp=2/Kr=20、校正 ±48 V 等信息，以及 `双QPR修改说明.md` 中电压外环 QPR，均不等于当前源文件，不能作为当前算法证据。

## 模型对象与实物工作点差异

| 项目 | 保存的模型 | 用户确认的实物 |
|---|---|---|
| 参考/母线 | 24 Vrms、50 Hz；两套 48 V 电源，各串 0.05 Ω | 24 Vrms 目标 |
| 每台桥滤波电感 | 两只 300 µH，差模总 600 µH | 两只 220 µH，差模总 440 µH |
| 每台输出滤波电容 | 2.2 µF，并显式串 1 Ω | 2.2 µF，没有显式串阻 |
| 负载 | 12 Ω | 12 Ω / 空载 |
| 从机 | 默认 PWM 与电流 PR 同时运行 | 从机栅关断 |
| PWM | 20 kHz 三角载波，互补 NOT，无死区 | HRTIM，包含死区设置及比较寄存器预装载 |
| 电压外环 | 连续 TransferFcn | 20 kHz Tustin |
| 反馈 | 理想电压/电流测量 | 标定后的 ADC，含偏移/增益及实际链路误差 |
| PR 输出实施 | 模型当前采样时刻更新，立即作用于 PWM 比较 | 回调计算后写预装载，下一谷底装载 |

原模型 `powergui`：离散电路步长 200 ns，Tustin/Backward Euler；主求解器自动可变步，MaxStep=0.5 µs；保存 StopTime=0.1 s。该 0.1 s 不足以单独证明谐振状态充分稳态。

## 关断从机后的电气连接

原模型两个输出端口 P/N 接同一公共负载。从机输出 RC 支路直接位于从机 P/N 之间。因此仅把从机四个栅极置零，第二只 2.2 µF 仍跨公共输出，总电容量仍为 4.4 µF；它不因 MOSFET 关栅而消失。从机两只电感及 MOSFET 的体二极管/100 kΩ snubber 也仍连在电路中。

实物第二只电容在“关从机”后是否仍跨输出，尚待确认。下面开关仿真采用模型的实际接线，明确保留它，不把关栅等同于拔掉整个从机。

## 空载反馈量级

24 Vrms、50 Hz 下，单只 2.2 µF 的 **50 Hz 基波**电容电流约 `2πfCV=16.6 mArms`；两只并联约 33.2 mArms，开关纹波电流另计。当前主电流换算中一个 ADC 码约 `3×2.400384/2048=3.516 mA`。负载为 12 Ω 时负载电流约 2 Arms，空载因此对电流反馈残余零偏、噪声和采样相位更敏感。该量级关系是静态推导，不能证明实物已出现这些误差。

实物万用表 DM3058E 的交流档读约 25 V，尚未取得固件全速采样的 RMS/直流均值/峰值；模型与这次静态对照不能判定 25 V 来自采样增益、波形畸变还是闭环振荡。

## 独立仿真说明

`inspect_model.m` 编译检查实际采样时间。

`run_switching_cases.m` 已完成原默认主从、12 Ω / 空载两组 1 s 开关仿真，每组末 0.2 s 统计。原计划的其他六组已取消，脚本也已缩减为这两组。

`run_priority_cases.m` 优先模拟 440 µH、关从机栅、显式电容串阻为 0 Ω 的 12 Ω / 空载，并以 1 Ω 空载作为阻尼对照。每组仿真 0.3 s，只统计 0.2–0.3 s；这是有限时长仿真观察，不能称充分稳态或实物验证。

空载用负载电阻 1 GΩ 近似。每次均从原 SLX 重新加载，在内存中改变参数与栅极信号，`close_system(mdl,0)` 不保存原模型。仿真保留原模型理想反馈、零采样计算延迟、连续虚拟阻抗和无死区假设；结果不能替代实际固件对象仿真或上板验证。

| 同上，增加完整调制度 50 µs UnitDelay + 采样保持 | 1 s / 0.8–1 s | **28.521784 V** | **0.316087 V** |

**当前保存参数下，原模型本身的主从空载已出现高频振荡。** 末 0.2 s 的输出 RMS 为 27.5913 V、峰值 54.0175 V，两台输出支路电流均约 0.62408 Arms（空载为相反方向的环流）。完整轨迹中，0.08–0.1 s 窗口 RMS 就已为 27.50798 V，因此不能把短 StopTime 当成本次仿真问题被掩盖的已证实原因。原模型在当前参数下并不支持“所有空载情形都稳定在 24 V”的说法。

相比之下，0.3 s 的关从机短仿真内，移除串阻并改变 L 尚未单独复现 25 V 漂移。无串阻的加载/空载窗口均值差按空载值归一约 0.3262%，但 0.3 s 的带载曲线仍在缓慢收敛，不能把它报告为最终稳态负载调整率，也不能用短仿真来认定关从机长期稳定。模型没有实际 MCU 的采样、计算及下一周期 PWM 装载延迟，必须与包含该延迟的真实 C 对象仿真分别看待。

另外两组已经使用同条件 440 µH / 电容串阻 0 / 从机四栅关断延长到 1 s：`run_extended_master.m` 保留原模型时序；`run_delayed_master.m` 在主机调制度进入 PWM 前增加采样 50 µs、初值 0 的 UnitDelay。延迟块编译采样时间实测为 `[5e-5,0]`，它同时把完整调制度按 50 µs 采样保持。后一组的电压外环仍为原连续 TransferFcn，并非对固件离散外环的精确复刻。

无额外延迟组在 1 s 内未见慢增长，末窗口约 24.0145 V；显式延迟组出现明显高频振荡，末窗口约 28.5218 V、峰值 54.4693 V。这是同一开关模型中控制时序假设对空载稳定性的直接对照，支持“原仿真没有包含足够的数字控制作用延迟，不能直接沿用其空载稳定性结论”的判断。它不能证明实物的精确延迟、寄生参数、反馈标定均与实验相同，也不能证明单独消除某个延迟就能修复实物。

## 基波与振荡分量

对上述 1 s 仿真的 0.8–1 s、2 µs 采样波形做独立正弦/余弦投影与残差 FFT：

| 工况 | 50 Hz 基波 RMS | 去除基波和直流后的 RMS | 500 Hz–20 kHz 最强频点 |
|---|---:|---:|---:|
| 原主从、12 Ω | 23.98935 V | 0.25708 V | 1050 Hz |
| 原主从、空载 | **24.00733 V** | **13.61755 V** | **约 3.095 kHz** |
| 440 µH 关从机空载、原时序 | 24.00969 V | 0.48863 V | 约 3.650 kHz |
| 同上、加 50 µs 延迟 | **24.07869 V** | **15.33123 V** | **约 3.725 kHz** |

振荡工况的 50 Hz 基波仍接近 24 V，而高频分量显著抬高总 RMS；因此“交流档读到高于 24 V”在这些仿真中不等同于“50 Hz 基波幅值升高相同幅度”。这些数值是仿真波形分析，不能把它们直接当成实物频谱。波形仅按 2 µs 保存，频谱与波形 RMS 是独立分析量；主结果仍以原 trueRMS 测量块输出为准。
