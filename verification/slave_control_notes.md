# 从逆变器控制说明

- 上电：主机开环，从机C/D四个PWM输出禁用；C/D计数器与M/A/B同时启动。
- PE0原按键：切换主机开闭环。切回开环时立即禁用从机输出，清除接入请求。
- PB9松手：主机闭环时切换从机接入/退出；开环时忽略。原主机QPR重初始化功能已删除。
- 接入请求在主机参考电压±2V的过零附近执行。首次只装载C/D比较值，不更新A/B。
- 从机由ADC4低优先级回调运行独立PR电流环：桥电压指令=公共输出电压+PR电流校正。
- 电流参考为本拍主机实测电感电流乘slave_ratio_applied，不增加低通滤波。slave_current_ratio默认1（从/主=1），允许0~2；比例以每秒1逐步变化。
- 从机母线独立变量slave_dc_bus_voltage_v，默认48V；无母线ADC，应填实际值。
- 从机电流指令峰值限制3A；软件过流阈值5A。这些为初始调试值，需按实际功率器件、滤波电感和传感器核定；软件检测不能代替硬件快速保护。
- ADC4错误、样本不配对、执行跨拍、非有限输入或过流会锁存slave_fault_flags并禁用从机。故障后需重启，PB9不能清除故障。
- ADC1回调监视ADC4更新；从机运行时ADC4落后超过两拍也会关闭从机。
- ADC1/ADC2触发、ADC配置、主机QPR函数和A/B调制函数保留。新控制计算增加CPU负载，实际运行时间需上板测量。
- C/D死区设为DIV1、上升/下降各25tick，170MHz下约147ns；应以实测驱动/MOSFET关断时间确认。A/B死区没有修改。
- VOFA通道1~7保持，CH7为辅助电感电流。辅助零偏和增益仍需独立标定。
- PWM输出禁用仅指栅极发波关闭，不等于交流支路物理隔离；本程序没有控制输出接触器。
- 本次实现跟踪电感电流，未加入电容电流补偿，不能宣称已经满足输出负载电流的精确比例或环流指标。

## 验证

Keil目标dcac编译0错误、0警告，日志MDK-ARM/slave_current_build.log。
Tests/verify_slave.py执行实际从机辅助函数和PR代码，检查启动、按键联锁、过零接入、比例斜坡、故障关断、A/B不被从机写入，以及电压前馈/抗饱和。
原按键、VOFA帧和均值测试通过。主机PR初始化/开环/闭环函数及A/B调制函数与verification/slave_before快照逐函数比较一致。
以上为软件证据；没有下载程序或验证真实PWM、并联稳定性、保护动作和中断运行时间。
